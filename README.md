Pagina personal para contacto de clientes y muestra de habilidades.

**Secciones y descripción**
- Home: Bienvenida y presentación
- Proyectos: Muestra de proyectos realizados
- Contacto: Formulario para contacto

**Carpetas dentro de src**
- component: contendra  los componentes que se puedan reutilizar como barra de navegación y footer
- images: contendran las imagenes a utilizar
- pages: las paginas del sitio
  - proyects: dentro de pages y contendran los diversos proyectos realizados
- styles: estilos generales (styles.css) y paleta de colores(colors.css)

**Tecnologias:**
GatsbyJs, JavaScript y GraphQL




## 🚀 Quick start
1.  **Create a Gatsby site using the minimal starter.**
    npm init gatsby

2.  **Start developing.**
    npm run develop

3.  **Open the code and start customizing!**
    Your site is now running at http://localhost:8000!
    Edit `src/pages/index.js` to see your site update in real-time!
